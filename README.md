## About the Project

**LUMI** is a simple front-end e-commerce interface that displays a collection of everyday products. Users can browse products, search by name, filter by category or price, and manage items in a shopping cart.

The project focuses on a clean shopping experience, responsive layouts, and interactive functionality using core front-end technologies.

## Features

- **Product Catalog:** Displays 16 sample products across four categories.
- **Product Search:** Find products by name.
- **Category Filters:** Browse Bags, Watches, Shoes, and Accessories.
- **Price Filters:** Filter products by price range.
- **Shopping Cart:** Add products, increase or decrease quantities, and remove items.
- **Cart Summary:** Shows the total number of items and the total price.
- **Local Storage:** Keeps cart contents saved after refreshing the page.
- **Responsive Design:** Adapts the layout for desktop, tablet, and mobile screens.
- **Interactive UI:** Includes hover effects, cart panel, and clear-filter functionality.

## How the Cart Works

1. Select **Add to Cart** on a product.
2. Open the cart to view the selected items.
3. Use the plus and minus controls to change quantities.
4. Remove an item whenever you need.
5. The cart is saved automatically in your browser using Local Storage.

## Responsive Design

The layout uses CSS Grid, Flexbox, and media queries to provide a comfortable browsing experience on different screen sizes. Product cards and filter controls adjust to fit smaller screens.
